# NINJA471 Site
Public website for NINJA471, deployed via GitHub Pages with the custom
domain ninja471.com. Everything in this repo is PUBLIC — never add
internal planning documents, financial models, personal data, or
anything marked internal to this repo.

The CNAME file binds the ninja471.com domain — never modify or delete it.

Design system (apply to all pages consistently):
- Dark background, warm ivory text (#e8e6df)
- Accent color: cyan/blue #00a8ff
- Fonts: Cormorant Garamond (headings) + DM Mono / JetBrains Mono
- Restraint and refinement — minimal, no clutter
- Single-file site: all changes go in index.html

The earthquake monitor app is a SEPARATE repo (quake-monitor-japan);
it only shares the domain. Don't modify it from here.
